# Ближайшее число

**Источник:** Yandex Contest 2025.

## Условие

Найдите в массиве элемент, самый близкий по величине к данному числу.

Формат ввода
В первой строке задается одно натуральное число N, не превосходящее 1000 — размер массива.
Во второй строке содержатся N чисел — элементы массива, целые числа, не превосходящие по модулю 1000.
В третьей строке вводится одно целое число x, не превосходящее по модулю 1000.

Формат вывода
Выведите значение элемента массива, ближайшее к `x`. Если таких чисел несколько, выведите любое из них.
