# Просто квадрат

**Источник:** True Tech Champ 2025, алгоритмический трек, задача D.

## Условие

Телефонный номер в России состоит из 11 цифр. Его можно набрать в международном формате с кодом `7` или в локальном формате с кодом `8`. Для заданного трехзначного префикса нужно найти номера, для которых один из вариантов набора является простым числом, а другой — точным квадратом целого числа.

В ответе номер выводится без первой цифры (`7` или `8`) как строка из 10 символов, включая возможные ведущие нули.

## Входные данные

В первой строке задано число тестов `t` (`1 ≤ t ≤ 10^3`). В каждой из следующих строк дан трехзначный префикс.

## Выходные данные

Для каждого теста выведите количество подходящих номеров `k`, затем отсортированный по возрастанию список из `k` номеров.
