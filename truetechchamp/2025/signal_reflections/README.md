# Отражения сигнала

**Источник:** True Tech Champ 2025, алгоритмический трек, задача C.

## Условие

В метро тестируют передачу сигнала. Сечение тоннеля моделируется окружностью единичного радиуса с центром в точке `(0, 1)`. Передатчик и приемник находятся в начале координат `(0, 0)`.

Сигнал выходит из начала координат под углом `p/q` градусов к оси `x`. Достигнув окружности, он отражается по закону: угол падения относительно радиуса окружности равен углу отражения. Процесс заканчивается, когда сигнал снова попадает в начало координат.

Для каждой пары `p` и `q` определите количество отражений до попадания сигнала в приемник.

## Входные данные

В первой строке задано количество пар `t` (`1 ≤ t ≤ 10^5`). В следующих `t` строках находятся пары `p_i` и `q_i` (`1 ≤ p_i, q_i ≤ 10^16`).

Гарантируется, что `0 < p_i / q_i ≤ 90` и `gcd(p_i, q_i) = 1`.

## Выходные данные

Для каждой пары `(p, q)` выведите одно целое число — количество отражений до попадания сигнала в приемник.

Можно показать, что в заданных ограничениях это количество всегда является целым числом.

## Пример

### Входные данные примера

```text
6
1 2
30 1
8 9
45 2
3 14
15 1
```

### Выходные данные примера

```text
359
5
404
7
839
11
```
