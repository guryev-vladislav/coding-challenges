# Детализация и вирус

**Источник:** True Tech Champ 2025, алгоритмический трек, задача B.

## Условие

При запросе детализации телефонных разговоров оператор мобильной связи берет записи о звонках из базы, переводит их в нужный формат и передает пользователю.

Один пользователь запросил детализацию разговоров. К сожалению, его телефон был заражен вирусом, который случайно перемешал данные детализации.

Детализация представляет собой массив из `n` целых чисел `c_i`, не равных нулю. Положительное число `c_i` обозначает установление соединения в момент времени `c_i` секунд с начала периода детализации, отрицательное число `c_i` — разрыв соединения в момент времени `-c_i` секунд.

Одновременно может быть активно только одно соединение. Поэтому записи о каждом соединении в корректной детализации должны стоять рядом, причем сначала должна идти запись об установлении соединения, а затем — о разрыве.

Например:

- записи `123` и `-456` означают соединение длительностью `456 - 123 = 333` секунды;
- записи `111` и `-111` означают соединение длительностью `0` секунд;
- записи `-234` и `234` означают, что новое соединение было установлено сразу после завершения предыдущего.

Детализация не может содержать данные о соединениях, которые были начаты или завершены вне периода детализации.

Вирус только переставляет записи. Проверьте, можно ли восстановить корректную детализацию. Если можно, определите суммарное время, в течение которого были активны соединения.

## Входные данные

В первой строке задано количество тестовых примеров `t` (`1 ≤ t ≤ 5`). Далее следуют `t` тестовых примеров.

Каждый тестовый пример состоит из двух строк:

1. В первой строке задано количество записей `n` (`1 ≤ n ≤ 10^5`).
2. Во второй строке заданы `n` целых чисел `c_i` (`-10^9 ≤ c_i ≤ 10^9`, `c_i ≠ 0`).

Если `c_i > 0`, соединение было установлено в момент времени `c_i`. Если `c_i < 0`, соединение было разорвано в момент времени `-c_i`.

## Выходные данные

Для каждого тестового примера выведите суммарное время соединения или `-1`, если в данные были внесены искажения, отличные от перестановки записей.

## Примеры

### Пример 1

#### Входные данные — пример 1

```text
1
6
11 4 -6 8 -9 -16
```

#### Выходные данные — пример 1

```text
8
```

#### Входные данные — пример 2


```text

0
-1
```
