# MWS-подобное слово

**Источник:** True Tech Champ 2026, алгоритмический трек.

## Условие

При развороте записи слова на 180 градусов буквы `M` и `W` меняются
местами, а `S` переходит в себя. Слово является MWS-подобным, если полученная
запись является перестановкой исходного слова.

Для заданной длины `n` найдите лексикографически наименьшее MWS-подобное слово,
составленное из букв `M`, `W` и `S`. Порядок букв: `M < S < W`.

## Входные данные

В единственной строке задано целое число `n` — длина слова.

## Выходные данные

Выведите лексикографически наименьшее MWS-подобное слово длины `n`.

## Идея решения

После разворота количество `M` становится количеством `W`, поэтому условие
выполняется тогда и только тогда, когда количество `M` равно количеству `W`.
Чтобы минимизировать слово, нужно использовать максимально возможное число пар
`M` и `W`, поставить все `M` в начало, а все `W` — в конец. Если `n` нечётно,
единственная оставшаяся буква `S` ставится между ними.
