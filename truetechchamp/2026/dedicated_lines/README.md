# Выделенные линии

**Источник:** True Tech Champ 2026, алгоритмический трек.

## Условие

Изначально остаточная ёмкость интернет-канала равна `100` процентам, а доход
равен нулю. В течение `n` дней руководитель каждый день выбирает одну из двух
стратегий:

- при расширении остаточная ёмкость уменьшается на `s_i`, а доход увеличивается
  на `t_i`;
- при апгрейде оборудования остаточная ёмкость увеличивается на `p`, но не
  может стать больше `100`, а доход не меняется.

Если после расширения остаточная ёмкость становится равной нулю или меньше,
пользователи теряют доступ к интернету, поэтому такая стратегия недопустима.

Определите максимальный доход после `n` дней, если руководитель должен
проработать весь срок.

## Входные данные

В первой строке заданы целые числа `n` и `p`:

- `1 <= n <= 10^4` — срок работы в днях;
- `0 <= p <= 99` — прирост остаточной ёмкости при апгрейде.

В следующих `n` строках заданы целые числа `s_i` и `t_i`:

- `1 <= s_i <= 99` — уменьшение остаточной ёмкости при расширении;
- `1 <= t_i <= 10^5` — доход от расширения.

## Выходные данные

Выведите максимальный суммарный доход.

## Пример

Вход:

```text
3 10
51 2026
52 2027
50 2
```

Выход:

```text
2028
```

## Идея решения

Динамика хранит максимальный доход для каждой остаточной ёмкости от `1` до
`100` после обработанных дней. На очередном дне из каждого достижимого
состояния выполняются два перехода: апгрейд или расширение, если после него
ёмкость остаётся положительной. Сложность решения — `O(n * 100)`, память —
`O(100)`.
