# Блокировки и разблокировки

**Источник:** True Tech Champ 2026, алгоритмический трек.

## Условие

Графический ключ строится на девяти узлах, расположенных в квадрате `3 x 3` и
пронумерованных как клавиши телефона:

```text
1 2 3
4 5 6
7 8 9
```

Пользователь начинает с произвольного узла и затем каждый раз выбирает зелёный
узел. Между активным и выбранным узлом проводится отрезок. Если отрезок проходит
через зелёный узел, этот узел также становится красным и больше не может быть
выбран.

По заданной строке из различных цифр от `1` до `9` определите, соответствует ли
она корректному графическому ключу. Если соответствует, найдите сумму квадратов
длин участков, на которых звенья ключа самоперекрываются.

Самопересечения без перекрытия не учитываются. Если два отрезка имеют общий
участок длины `1`, в ответ добавляется `1`.

## Входные данные

В первой строке задано целое число `t` — количество тестовых примеров
(`1 <= t <= 25000`).

В следующих `t` строках заданы строки длины от `4` до `9`, состоящие из различных
цифр от `1` до `9`.

## Выходные данные

Для каждого тестового примера выведите:

- `-1`, если строка не задаёт корректный ключ;
- `0`, если корректный ключ не имеет самоперекрытий;
- сумму квадратов длин перекрывающихся участков в противном случае.

## Примеры

### Пример 1

Вход:

```text
3
3791
3795
5469
```

Выход:

```text
0
-1
1
```

### Пример 2

Вход:

```text
1
123456789
```

Выход:

```text
0
```

## Идея решения

Сначала последовательно моделируется окрашивание узлов и проверяется, что каждый
выбранный узел ещё зелёный. Затем каждая пара звеньев проверяется на
коллинеарность. Для коллинеарных отрезков длина общего участка вычисляется по
проекции на горизонтальную или вертикальную ось.
