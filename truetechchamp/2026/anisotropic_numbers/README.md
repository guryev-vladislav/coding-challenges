# Анизотропные номера

**Источник:** True Tech Champ 2026, алгоритмический трек.

## Условие

Телефонный номер состоит из 11 цифр. Первые 4 цифры — код страны и оператора,
или префикс.

Номер называется анизотропным, если на семисегментном индикаторе кнопочного
телефона он одинаково читается в исходном положении и после поворота на 180
градусов.

При повороте цифры преобразуются следующим образом:

- `0` переходит в `0`;
- `2` переходит в `2`;
- `5` переходит в `5`;
- `8` переходит в `8`;
- `6` переходит в `9`;
- `9` переходит в `6`.

Остальные цифры после поворота не соответствуют корректным цифрам.

Дан префикс телефонного номера. Необходимо определить количество анизотропных
телефонных номеров с этим префиксом.

## Входные данные

В единственной строке задан префикс — строка из 4 цифр от `0` до `9`.

## Выходные данные

Выведите количество анизотропных телефонных номеров с заданным префиксом.

## Примеры

### Пример 1

Вход:

```text
8916
```

Выход:

```text
0
```

### Пример 2

Номер `89062529068` является анизотропным: после поворота на 180 градусов
порядок цифр меняется на обратный, а сами цифры преобразуются так, что номер
остаётся равен исходному.

Номер `0000010000` не является анизотропным, поскольку цифра `1` после поворота
не соответствует корректной цифре.
