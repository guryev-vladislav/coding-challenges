# Главное — честная игра

**Источник:** True Tech Champ 2026, алгоритмический трек.

## Условие

Даны две дроби `p1/q1` и `p2/q2`, где `p1 <= p2` и `q1 <= q2`. Необходимо
рассмотреть все дроби `x/y`, для которых:

```text
p1 <= x <= p2
q1 <= y <= q2
```

Для каждой дроби записывается десятичное представление в формате `a.b(c)`, где
`b` — непериодическая часть, а `c` — периодическая. Для конечной дроби в
скобках записывается один ноль. Требуется найти общее количество цифр во всех
периодических частях.

Ответ выведите по модулю `998244353`.

## Входные данные

В первой строке заданы `p1` и `q1`, во второй — `p2` и `q2`.

Ограничения:

- `0 <= p1 <= p2 <= 10^9`;
- `1 <= q1 <= q2 <= 10^9`;
- `q2 - q1 <= 5 * 10^4`.

## Выходные данные

Выведите сумму длин периодов всех дробей `x/y` по модулю `998244353`.

## Примеры

### Пример 1

Вход:

```text
12 10
13 12
```

Выход:

```text
8
```

### Пример 2

Вход:

```text
3 10
20 26
```

Выход:

```text
1592
```

## Идея решения

Длина периода дроби `x/y` равна мультипликативному порядку числа `10` по
модулю `y/gcd(x,y)` после удаления всех множителей `2` и `5`. Для каждого
знаменателя перебираются его делители `d`. Значение для всех числителей с
`gcd(x,y) = d` восстанавливается преобразованием Мёбиуса из значений для
делителей.

Знаменатели факторизуются сегментированным решетом, а порядки по простым
степеням кэшируются. Это позволяет работать с коротким диапазоном знаменателей
при больших значениях самих чисел.
