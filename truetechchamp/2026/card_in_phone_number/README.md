# Номер карты в телефоне

**Источник:** True Tech Champ 2026, алгоритмический трек.

## Условие

Первые восемь цифр номера банковской карты имеют вид `2200xxxx`. Полный номер
карты неизвестен, но фиксирован. Телефонный номер состоит из `7`, заданного
трёхзначного префикса, начинающегося с `9`, и семизначной основной части.

Нужно определить, сколько телефонных номеров с данным префиксом содержат первые
восемь цифр номера карты в качестве непрерывной подстроки.

## Входные данные

В единственной строке задан трёхзначный префикс телефонного номера. Он состоит
из цифр и начинается с `9`.

## Выходные данные

Выведите количество подходящих телефонных номеров.

## Идея решения

Подстрока длины 8 в номере длины 11 может начинаться только с одной из первых
четырёх позиций. Начало с позиции 0 невозможно, поскольку номер начинается с
`7`, а начало с позиции 1 невозможно, поскольку первая цифра префикса равна
`9`.

Если две последние цифры префикса равны `22`, подстрока может начаться с
позиции 2. В этом случае первые шесть цифр основной части фиксированы, а
последняя цифра свободна, поэтому существует `10` номеров.

Если последняя цифра префикса равна `2`, подстрока может также начаться с
позиции 3. Тогда вся основная часть номера определяется однозначно, поэтому
добавляется ещё один номер. Эти два случая не пересекаются.
